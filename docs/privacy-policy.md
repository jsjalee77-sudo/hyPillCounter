# 정알약계수 개인정보처리방침

시행일: 2026년 11월 14일

정알약계수(이하 "앱")는 이용자의 개인정보를 수집하지 않습니다. 이 방침은 앱이 사용하는 권한과 데이터 처리 방식을 설명합니다.

## 1. 수집하는 개인정보
앱은 이름, 연락처, 위치, 기기 식별자 등 **어떠한 개인정보도 수집하지 않으며**, 운영자나 제3자의 서버로 전송하지 않습니다.
앱에는 인터넷 접근 권한이 없어 외부와 통신할 수 없습니다.

## 2. 사용하는 권한
| 권한 | 목적 |
|---|---|
| 카메라 | 트레이 위의 알약을 촬영하여 개수를 세기 위해 사용합니다. |
| 진동 | 목표 수량 일치/불일치를 알리기 위해 사용합니다. |

갤러리 사진은 이용자가 직접 선택한 사진에만 접근합니다(Android 사진 선택 도구 사용).

## 3. 기기에 저장되는 정보
- 계수 결과(시각, 수량, 목표 수량, 보정 내역)와 촬영 이미지는 **이용자의 기기 내부 저장소에만** 저장됩니다.
- 사진 분석은 모두 기기 안에서 처리되며 외부로 전송되지 않습니다.
- 클라우드 자동 백업을 사용하지 않습니다.
- 이용자는 앱의 이력 화면에서 기록을 삭제할 수 있으며, 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.

## 4. 이용자가 직접 내보내는 경우
이력 화면의 "학습 데이터 내보내기"를 누르면 저장된 이미지와 알약 위치 정보가 zip 파일로 만들어지고,
이용자가 선택한 앱(메일, 드라이브 등)으로 공유됩니다. 이 기능은 이용자가 직접 실행할 때만 동작하며,
공유된 파일의 처리는 이용자가 선택한 서비스의 정책을 따릅니다.
처방전, 환자 이름 등 개인정보가 사진에 찍히지 않도록 주의해 주세요.

## 5. 아동의 개인정보
앱은 약국 업무용으로 만들어졌으며 아동을 대상으로 하지 않습니다.
